1R/La encapsulación permite ocultar datos internos de las distintas clases y es importante 
    porque es la que permite proteger los datos controlando y permitiendo su acceso mediante métodos públicos 

    2R/La diferencia es que el constructor sirve a la hora de iniciar la creación de un objeto y el método
    es el que define el comportamiento o la acción que va a ejecutar el objeto cuando ya fue creado

    3R/Los atributos deben ser privados porque se deben proteger los datos evitando así el acceso
    directo desde otras clases y esto sirve para evitar modificaciones erróneas.

    4R/El getters permite leer el valor de un atributo privado devolviéndole su valor y setters 
    es el que permite modificar el valor de los atributos 

    5R/(Falso)Porque el método setter si valida los datos a la hora de colocarlos para de esta forma
    evitar valores incorrectos dentro del objeto
